# Phase 13 — Full QA and production polish

## Goal

Treat Favour as though real beta users will use it immediately. Review and fix, not merely report.

## Critical journeys

Test end-to-end where environment configuration allows:

1. Landing → sign up → onboarding → five favourites → taste profile → home
2. Recommendation detail → Love → persistence
3. Not for me → replacement
4. Search → real item → Love → learning signal
5. Save → Saved → unsave
6. Ask Favour → film request → verified results
7. Travel request → verified destination/place
8. Sign out → sign in → state preserved
9. Reset taste
10. Delete account

- generic SaaS
- cluttered
